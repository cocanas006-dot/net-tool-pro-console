# net-tool
Official network tools and scripts for the Pro Console terminal app. Download and manage tools directly from the console

 # 🚀 Pro Console Guide

Welcome to the most powerful terminal for Android! Use these commands to manage your tools.

### 🛠️ Basic Commands
* `/help` - Show all commands.
* `/clear` - Clean the screen.
* `/support` - subscribe owner.

### 📦 Package Manager
* `/pkg install git` - Install the real Git engine.
* `/pkg install net` - Install networking tools.

### 🌐 Real Git Features
* `/git clone [URL]` - Clone real code to your phone!

### 💎 Premium
* `/premium` - Support the dev and remove ads.
